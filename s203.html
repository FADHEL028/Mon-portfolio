SAÉ S2.03 — Projet individuel

Installation de Services Réseaux

Déploiement d'une infrastructure serveur Linux (LAMP, FTP, SSH, Virtualization & Analyse de trames)

Environnement Debian / Linux
Stack Web LAMP (Apache, MariaDB, PHP)
Sécurité & Réseau SSH, vsftpd, Wireshark, .htaccess

Contexte

Cette SAÉ s'inscrit dans le cadre de l'apprentissage des services réseaux avancés sous Linux. L'objectif principal était d'installer, de configurer et de sécuriser un environnement serveur complet **LAMP** (Linux, Apache2, MariaDB, PHP) sur une machine poste client, puis de déployer divers services réseaux (FTP, SSH, VirtualBox) tout en effectuant des analyses de trames pour comprendre les mécanismes de sécurité et d'encapsulation.

Objectifs & Configurations clés

  • Stack LAMP & Base de données : Déploiement du serveur web Apache2 avec extension PHP-PDO et installation du SGBD MariaDB[cite: 3]. Création d'un utilisateur et d'une base de données dédiée avec gestion stricte des privilèges SQL.
  • Développement Web Dynamic : Conception d'une page PHP interrogeant la base de données (table personnes) et sécurisation du répertoire public_html via authentification .htaccess.
  • Serveur FTP (vsftpd) : Configuration fine autorisant le téléchargement anonyme et restreignant le téléversement (upload) aux comptes utilisateurs locaux[cite: 3].
  • Sécurisation SSH : Hardening du service SSH (désactivation des connexions root directes, changement du port standard pour le port 60122) et déploiement d'une authentification par paire de clés asymétriques (RSA/ED25519) sans mot de passe.
  • Analyse réseau & Virtualisation : Capture et étude de paquets HTTP/FTP non chiffrés via Wireshark (analyse du codage Base64)[cite: 3] et mise en place d'un environnement de simulation réseau Marionnet sous VirtualBox.

Extrait de Script & Configuration

Voici un aperçu de la connexion PDO PHP vers le SGBD MariaDB ainsi que de la configuration de sécurisation du service SSH[cite: 3].

index.php / sshd_config Télécharger les scripts de conf 
<?php
// Connexion PDO sécurisée au SGBD MariaDB
$dbuser = 'e12345678';
$dbname = 'e12345678';
$password = 'SecretPass123!';

try {
    $conn = new PDO("mysql:host=localhost;dbname=$dbname;charset=utf8", $dbuser, $password);
    $conn->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
} catch (PDOException $e) {
    die("Pb connexion base de données $dbname: " . $e->getMessage());
}

$sql = "SELECT Nom, Prénom, Tél FROM personnes";
$req = $conn->query($sql);
?>

# Configuration /etc/ssh/sshd_config (Hardening SSH)
Port 60122
PermitRootLogin no
PubkeyAuthentication yes
AuthorizedKeysFile .ssh/authorized_keys

Architecture & Protocoles

Le projet met en avant l'interaction entre les différentes couches applicatives et protocolaires :

  • Service Web : Apache2 / HTTP (Port 80) avec module PHP, réécriture d'URL et restriction d'accès.
  • Stockage de données : MariaDB avec connecteur pdo_mysql et encodage natif UTF-8.
  • Transfert de fichiers : FTP via vsftpd (Ports 20/21) testé en ligne de commande via lftp.
  • Administration distante : SSH (Port 60122) sécurisé par échange de clés d'empreinte publique.
  • Analyse & Encapsulation : Inspection du modèle OSI (HTTP/TCP/IP/Ethernet) sous Wireshark.
