SAÉ S1.01 — Binôme

Le Choixpeau pas Magique

Développement d’un algorithme de répartition algorithmique

Langage Python 3
Fichier principal s101.py
Modalité Travail en Binôme

Contexte

Cette SAÉ consiste à concevoir un programme capable de répartir automatiquement des élèves dans différentes catégories à partir d’un questionnaire. Le projet s’inspire d’un système de décision basé sur des critères bien définis.

Objectifs

  • Respecter un cahier des charges fonctionnel et rigoureux
  • Développement du script principal s101.py
  • Implémenter une logique de décision déterministe
  • Tester et valider formellement les résultats produits

Script Python (s101.py)

Le cœur du projet réside dans le fichier s101.py. Il contient la logique d'acquisition des données, les fonctions d'évaluation ainsi que l'algorithme d’affectation aux différentes maisons/catégories.

# Code de la SAE S101 (uniquement les définitions de fonction)

def nombre_eleves(reponses):
    return len(reponses) / 5

def eleves(reponses):
    e = []
    i = 0
    while i < len(reponses):
        e.append(reponses[i])
        i += 5
    return e

def lecture_reponses(nom_fichier):
    rep = []

    f = open(nom_fichier)
    lignes = f.readlines()
    f.close()

    # Pour chaque ligne
    i = 0
    while i < len(lignes):
        cut = lignes[i].split(":")
        # Ajout du nom
        rep.append(cut[0])
        scores = cut[1].split("/")
        j = 0
        while j < len(scores):
            rep.append(int(scores[j]))
            j += 1
        i += 1
    return rep


def maison(reponses, indice):
    ind_score_max = 0
    
    # Parcours des scores. Chaque score se trouve à l'indice indice + 1
    j = 0
    while j < 4:
        if reponses[indice + 1 + j] > reponses[indice + 1 + ind_score_max]:
            ind_score_max = j
        j += 1
    #ind_score max est un nombre entre 0 et 4 correspondant à la question où l'élève a mis le score maximum
    m = ["Gryffondor", "Serdaigle", "Poufsouffle", "Serpentard"]
    return m[ind_score_max]

def repartition(reponses):
    aff = {}
    i = 0
    while i < len(reponses):
        aff[reponses[i]] = maison(reponses, i)
        i += 5
    return aff

def nb_erreurs(d1, d2):

    nb_erreurs = 0
    
    # Parcours de la liste des élèves
    eleves = list(d1)
    i = 0
    while i < len(d1):
        if d1[eleves[i]] != d2[eleves[i]]:
            nb_erreurs += 1
        i += 1
    return nb_erreurs

Principe de fonctionnement

Le programme repose sur un questionnaire comportant 4 questions clés. Chaque réponse est évaluée avec un score compris entre 1 et 10. L’élève est ensuite affecté à une catégorie en fonction de son score prédominant.

  • Question 1 → Profil orienté action
  • Question 2 → Profil intellectuel
  • Question 3 → Profil social
  • Question 4 → Profil ambitieux
