SAÉ S1.03

Installation & configuration d’un poste de développement

Contexte

Cette SAÉ consistait à installer un système d'exploitation Linux et à configurer un environnement complet de développement personnalisé, prêt pour la réalisation et le déploiement de projets informatiques.

Objectifs

  • Installer et configurer un système Linux dédié
  • Configurer un environnement de développement logiciel complet
  • Mettre en place et sécuriser un serveur web local
  • Installer et administrer une base de données relationnelle

Technologies utilisées

Linux (Ubuntu / Kubuntu) Apache2 PHP PostgreSQL Java Python Bash & Terminal

Réalisations techniques

  • Création d’une clé USB bootable d'installation
  • Installation complète du système d'exploitation et partitionnement du disque
  • Configuration des accès réseau et de l'environnement universitaire (Eduroam)
  • Installation et configuration du serveur HTTP Apache2
  • Déploiement d’un site web applicatif en environnement local
  • Installation, sécurisation et configuration de PostgreSQL
  • Exécution et validation de tests d'interaction avec PHP

Difficultés rencontrées

  • Gestion du partitionnement avancé du disque dur
  • Prise en main approfondie des commandes système Linux
  • Configuration fine et orchestration des services réseaux
  • Gestion rigoureuse des droits d'accès et des permissions système

Résultats

Un environnement de développement local performant, sécurisé et totalement fonctionnel a été mis en place, permettant le développement et le test fluide d'applications web intégrant une base de données.

Compétences développées

Linux Administration système Serveur Web Base de données Terminal & Scripting

Cas pratique

Mise en place d’une application web locale accessible via localhost, articulée autour de scripts PHP et d'interactions en temps réel avec la base de données PostgreSQL.
