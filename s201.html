Find My Word

Conception et développement d'une application de devinette de mots orientée objet

Langage Java 11 / POO
Architecture Séparation Modèle / Vue
Données JSON / WordSet API

Contexte

Cette SAÉ s'inscrit dans la ressource R201 — Développement orienté objet. L'objectif était de concevoir une version adaptée du jeu populaire Wordle, baptisée Find My Word. Le joueur doit deviner un mot secret de 5 lettres en un maximum de 6 tentatives[cite: 4], en s'aidant des indications de présence et de position fournies après chaque essai[cite: 4].

Objectifs & Principes POO

  • Appliquer les principes fondateurs de la POO : encapsulation, héritage et polymorphisme[cite: 4].
  • Assurer une séparation stricte des responsabilités entre le moteur de jeu et l'affichage console[cite: 4].
  • Modéliser le domaine d'application à l'aide de diagrammes de classes UML[cite: 4].
  • Charger dynamiquement des mots secrets à partir d'un fichier JSON via l'API dédiée[cite: 4].
  • Valider formellement la conformité des propositions par un jeu de tests unitaires automatisés[cite: 4].

Extrait de Code (Game.java)

Voici un extrait du moteur de jeu principal encapsulant la boucle de partie et l'analyse des tentatives[cite: 4].

public class Game {
    private final IWordRepository repository;
    private final Player player;
    private Word secretWord;
    private final List<Attempt> attempts;
    private static final int MAX_ATTEMPTS = 6;

    public Game(IWordRepository repository, Player player) {
        this.repository = repository;
        this.player = player;
        this.attempts = new ArrayList<>();
    }

    public void startNewGame() {
        this.secretWord = repository.getRandomWord();
        this.attempts.clear();
    }

    public LetterResult[] playAttempt(Word candidate) {
        if (!candidate.isValid()) {
            throw new IllegalArgumentException("Mot invalide.");
        }
        LetterResult[] results = secretWord.compareWith(candidate);
        attempts.add(new Attempt(candidate, results));
        return results;
    }

    public boolean isWon() {
        if (attempts.isEmpty()) return false;
        Attempt last = attempts.get(attempts.size() - 1);
        return last.isAllCorrect();
    }

    public boolean isGameOver() {
        return isWon() || attempts.size() >= MAX_ATTEMPTS;
    }
}

Architecture & Conception

Le projet est découpé de manière modulaire selon les rôles définis dans le sujet[cite: 4] :

  • Game : Orchestration de la partie, suivi des essais et calcul du score[cite: 4].
  • Word & Attempt : Encapsulation des mots de 5 lettres et vérification des règles de validité[cite: 4].
  • IWordRepository : Interface permettant de basculer entre un dépôt réel (JSON) et un dépôt fixe pour les tests (FixedWordRepository)[cite: 4].
  • ConsoleView : Gestion des entrées/sorties utilisateur et affichage de la grille[cite: 4].

Analyse & Analyse des Lettres

Après chaque mot proposé, le programme associe un état à chaque lettre[cite: 4] :

  • OK : La lettre est correcte et bien placée à sa position[cite: 4].
  • PRESENT : La lettre appartient au mot mais se trouve à une autre position[cite: 4].
  • ABSENT : La lettre n'apparaît pas dans le mot secret[cite: 4].
