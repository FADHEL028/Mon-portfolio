II. Modélisation des Données (Livrable 2)

La modélisation s'appuie sur une analyse des entités métiers pour garantir une structure relationnelle normalisée :

  • Station — Prix — Carburant : Historisation des prix selon le carburant et la date de mise à jour.
  • Station — Rupture — Carburant : Suivi des périodes d'indisponibilité par type de carburant.
  • Station — Service : Association plusieurs-à-plusieurs gérée via la table station_service.
  • Horaire : Plages d'ouverture rattachées dynamiquement aux stations et à leurs services.

III. Architecture SQL & Traitements Python

Création des tables sous PostgreSQL et extraction des données imbriquées au format JSON via des scripts d'ETL Python :

script_creation_table.sql 
CREATE TABLE station (
    id_station INT PRIMARY KEY,
    localisation VARCHAR(255),
    adresse TEXT,
    enseigne VARCHAR(100)
);

CREATE TABLE carburant (
    id_carburant INT PRIMARY KEY,
    nom_carburant VARCHAR(50) NOT NULL
);

CREATE TABLE prix (
    id_prix SERIAL PRIMARY KEY,
    id_station INT REFERENCES station(id_station),
    id_carburant INT REFERENCES carburant(id_carburant),
    prix NUMERIC(5,3),
    date_maj TIMESTAMP
);

CREATE TABLE rupture (
    id_rupture SERIAL PRIMARY KEY,
    id_station INT REFERENCES station(id_station),
    id_carburant INT REFERENCES carburant(id_carburant),
    date_debut TIMESTAMP,
    date_fin TIMESTAMP
);
creation_vue.sql (Top 20 Stations Gazole) 
WITH PrixMoyenCarburant AS (
    SELECT AVG(prix) AS moyenne_nationale
    FROM prix p
    JOIN carburant c ON p.id_carburant = c.id_carburant
    WHERE c.nom_carburant = 'Gazole'
)
SELECT 
    s.id_station,
    s.localisation,
    p.prix AS prix_station,
    ROUND(p.prix - pm.moyenne_nationale, 3) AS ecart_a_la_moyenne,
    ROUND(((pm.moyenne_nationale - p.prix) / pm.moyenne_nationale) * 100, 1) AS pourcentage_economie
FROM station s
JOIN prix p ON s.id_station = p.id_station
JOIN carburant c ON p.id_carburant = c.id_carburant
CROSS JOIN PrixMoyenCarburant pm
WHERE c.nom_carburant = 'Gazole'
ORDER BY p.prix ASC
LIMIT 20;
